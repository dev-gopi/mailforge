# Built-in `activity-notification` (template 102)

Reproduces the supplied warm-minimal new-comment notification from the reference
package using reusable EmailDocument nodes; no custom HTML is required.

```ts
import { createEmail } from "@mailforge/email";
const email = createEmail({ brand: { name: "huddle" } });
const output = await email.render("activity-notification", {
  data: {
    brandName: "huddle", recipientName: "Jordan", actorName: "Mira Patel",
    itemName: "Design handoff",
    commentExcerpt: "The updated screens are ready for your review.",
    actionUrl: "https://example.com/discussions/123",
    preferencesUrl: "https://example.com/settings/notifications", year: 2026,
  },
  themeName: "modern",
});
console.log(output.subject, output.html, output.text);
```

Public exports: `activityNotificationSchema`, `ActivityNotificationData`,
`buildActivityNotificationTemplate`, and `activityNotificationPreviewData`
from `@mailforge/templates` (also available from `@mailforge/email`).
The template ID is present in `listBuiltinTemplates()` and the unified catalog.

Data fields: `brandName`, `recipientName`, `actorName`, `itemName`,
`commentExcerpt`, `actionUrl`, `preferencesUrl`, and `year` are required.
Optional localized copy: `categoryLabel`, `kicker`, `heading`,
`greetingPrefix`, `commentVerb`, `quoteLabel`, `buttonLabel`,
`footerNote`, and `preferencesLabel`.

`design` supports `accent`, `button`, `surface`, `canvas`, `text`, `muted`,
`quoteBackground`, `quoteBorder`, `cardBorder`, and `fontFamily`.
Use `themeName`/`theme` and standard document patches for broader styling.
All external links require absolute, credential-free HTTPS URLs.
User-provided actor/item/comment text is escaped and control-character checked.
Plain-text output is generated by the standard renderer.

Reusable capabilities added for this design:
- `rich-text` node with strongly typed, escaped inline segments (optional
  `strong` or hexadecimal `color`), not arbitrary HTML.
- `quote-panel` semantic style for configurable background and accent border.
- `data-mf-placement="after-shell"` on top-level sections for external footers.
- `data-mf-columns="keep-mobile"` on sections for mobile inline brand columns.

For reference-specific local preview run `node examples/activity-notification/render.mjs`.
Generate the whole catalog using `node scripts/generate-all-template-previews.mjs`
and verify with `node scripts/audit-release-previews.mjs`.
Browser previews are not Gmail/Outlook/Apple Mail certification.

preview generator. Source-level catalog registration does not update compiled
exports automatically. Run the V3 follow-up verification script after applying

