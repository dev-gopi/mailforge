MailForge Documentation

Enterprise-grade, type-safe email template engine with built-in responsive designs, dark mode, component registry, and delivery integrations.

📦 Monorepo Packages

Clean decoupled architecture: @mailforge/email, @mailforge/core, @mailforge/themes, @mailforge/preview, and @mailforge/testing.

XSS prevention, safe URL validation blocking javascript: vectors, and strict Gmail 102KB size budget checking.

Installation

# Install using pnpm, npm, or yarn
pnpm add @mailforge/email @mailforge/core @mailforge/themes
# Optional testing and preview tooling:
pnpm add -D @mailforge/testing @mailforge/preview

Quickstart

Render your first responsive HTML email in seconds:

import { createEmail } from "@mailforge/email";

// Initialize engine with your brand
const email = createEmail({
  brand: {
    name: "Acme Corp",
    primaryColor: "#2563eb",
    logo: "https://example.com/logo.png",
  },
  theme: "modern", // or "dark", "corporate", "minimal"
});

// Render a template with dynamic variables
const result = await email.render("welcome", {
  data: {
    user: { firstName: "Sarah" },
    actionUrl: "https://example.com/onboarding",
  },
});

console.log(result.subject); // "Welcome to Acme Corp, Sarah!"
console.log(result.html);    // Full responsive HTML markup
console.log(result.text);    // Plain text alternative

Template Compiler: compileTemplate

High-performance template compilation with HTML escaping, nested paths, fallbacks, conditionals, and loops.

import { compileTemplate } from "@mailforge/core";

// 1. Pre-compile reusable template
const render = compileTemplate(`
  <h1>Hello {{ user.name || 'Friend' }}!</h1>
  {{#if isVip}}
    <p>Exclusive VIP perks apply!</p>
  {{/if}}
  <ul>
    {{#each items}}
      <li>{{@index}}: {{this}}</li>
    {{/each}}
  </ul>
`);

const html = render({
  user: { name: "Alex" },
  isVip: true,
  items: ["Express Delivery", "Gift Box"],
});

In-Memory Caching: MemoryCache

Production-ready LRU eviction and TTL cache for compiling templates and theme tokens:

import { MemoryCache } from "@mailforge/core";

const cache = new MemoryCache({
  maxSize: 1000,
  defaultTtlMs: 60 * 1000, // 1 minute TTL
});

cache.set("template:welcome", compiledWelcome);
const cached = cache.get("template:welcome");

Security: isSafeUrl

Protects against malicious XSS schemes (such as javascript:, vbscript:, data:) in email CTAs:

import { isSafeUrl, sanitizeUrl } from "@mailforge/core";

isSafeUrl("https://example.com");              // true
isSafeUrl("mailto:support@example.com");        // true
isSafeUrl("javascript:alert(1)");             // false
isSafeUrl("data:text/html,<script>");          // false

const safeHref = sanitizeUrl(untrustedUrl, "#");

Dark Theme: darkTheme

MailForge includes full dark-mode palette support conforming to ResolvedEmailTheme:

import { createEmail } from "@mailforge/email";
import { darkTheme } from "@mailforge/themes";

const email = createEmail({
  brand: { name: "DarkCo" },
  theme: "dark", // activates dark theme tokens automatically
});

Testing: @mailforge/testing

First-class test assertions and in-memory mock transports for testing email flows:

import {
  assertEmailContains,
  assertEmailValidHtml,
  assertEmailSizeWithinBudget,
  assertEmailHasUnsubscribe,
  createMockTransport,
} from "@mailforge/testing";

// Verify output
assertEmailValidHtml(result.html);
assertEmailSizeWithinBudget(result.html, 102400); // Gmail 102KB limit
assertEmailHasUnsubscribe(result.html);

// Dispatch through mock transport
const mock = createMockTransport();
await mock.sendMail({ to: "user@example.com", html: result.html });
mock.assertSentCount(1);

Preview & Diagnostics: @mailforge/preview

Inspect email quality, calculate deliverability scores, and render interactive preview frames:

import { renderPreviewFrame, inspectEmailQuality } from "@mailforge/preview";

const quality = inspectEmailQuality(result.html);
console.log(quality.score);            // 0-100 score
console.log(quality.exceedsGmailLimit);// boolean

const previewHtml = renderPreviewFrame({
  subject: result.subject,
  html: result.html,
  text: result.text,
});
